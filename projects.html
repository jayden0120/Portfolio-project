Portfolio Website

The website you are viewing now. I planned it with a site map and wireframes, then built it with semantic HTML and one external style sheet. It is published with GitHub Pages.

What I Practiced

  • Semantic elements: header, nav, main, section, article, aside, and footer
  • Mobile first design with a media query for larger screens
  • CSS Grid layouts that change on each page

Course Schedule Table

A class schedule built as an HTML table. I used rowspan and colspan to group headings and CSS to add borders, shadows, and striped rows.

What I Practiced

  • Table elements: caption, thead, tbody, th, and td
  • Striped rows with the nth-of-type() pseudo-class
  • Using a table for data, not for page layout

Customer Payment Form

A checkout style form with labels for every field, fieldsets to group information, and a layout that changes from one column to two columns on larger screens.

What I Practiced

  • Form controls: input, label, select, and textarea
  • Input types such as email and tel
  • The required attribute so the browser checks the form

Project Notes

All of these projects were created in CTS1831C Web Authoring I at Broward College.

Tools I Used

  • HTML5
  • CSS3
  • GitHub and GitHub Pages
  • W3C Markup Validation Service
